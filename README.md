# Excel Income Report Dashboard 2026

## Project Overview

This project is an Excel-based income reporting dashboard created using mock data. It analyses 2026 income performance across monthly trends, payment methods, quarterly results, working-day performance, and target achievement.

The project was designed as a portfolio dashboard to demonstrate practical reporting, data cleaning, KPI tracking, and business insight generation using Microsoft Excel.

## Objective

The objective of this project is to create a clear and interactive income reporting dashboard that helps users understand:

- Total income performance
- Monthly income trends
- Target achievement
- Payment method contribution
- Quarterly performance
- Working-day income patterns
- Key business insights

## Dataset

The workbook uses mock income data only. No confidential organisational, client, or personal information is included.

The dataset includes:

- Date
- Day
- Cash payments
- Eftpos Online
- Eftpos Offline
- Gift Card
- Internet Banking
- Daily total income
- Daily target
- Monthly income
- Quarterly income
- Payment method totals

## Dashboard Features

The Excel dashboard includes:

- KPI cards for total income, target, target gap, and achievement percentage
- Monthly income vs target analysis
- Payment method breakdown
- Quarterly income trend
- Working-day income performance
- Key insights summary
- Clean summary report sheet

## Key Insights

- Total income performance was compared against the annual target.
- Working-day logic was used so weekends were not unfairly treated as poor performance days.
- Eftpos Online was identified as the top payment method.
- Monthly and quarterly summaries were created to support business reporting.
- The dashboard provides a quick overview of performance for decision-making.
